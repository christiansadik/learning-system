# Review Over Time

Before accessing state, read [workspace.md](../_study/workspace.md), [review.md](../_study/review.md), and the response/attempt rules in [practice.md](../_study/practice.md). For prerequisite classification also read [explanation.md](../_study/explanation.md). All are bundled references; sibling skills need not be installed for standalone review.

1. **Load and inspect.** Select the main topic and migrate legacy state only with consent. Show due dates and eligibility from persisted records, not chat memory. Resume an active review through its owner and preserved question order; respect reservations across every selected topic. Never overwrite an unfinished drill, dialogue, or export.
2. **Enroll only explicitly.** If nothing is enrolled, use the review contract's standalone route: request the learner's confirmation of prior study and actual completion time. Do not fabricate completed workflow steps. Save eligibility and its basis, report the first due date, and stop without an immediate cumulative quiz. Existing enrollment is reused, not reset.
3. **Offer a due review.** On consent, use the contract's selection policy over eligible topics, prioritizing due/difficult material while improving coverage. Inspect actual sources and classify relevant prerequisites with rationale. Block or obtain explicit narrower scope when source evidence is unavailable; never silently fill gaps from memory.
4. **Prepare and wait.** Register supported questions and a question-only `review_questions` artifact. Create a saved review-purpose attempt using the shared response format and exact order. Present the default ten questions with five options each, fewer only when evidence or the learner's choice requires it. Save actual answers before correction and withhold solutions until the correction gate is met.
5. **Correct and report.** Follow the shared quiz rules for clarification, assistance, exclusions, pause, and abandonment. Derive per-topic/concept results, latest and historical percentages, coverage, and recommendations through the review contract. Cite sources; never equate a high score or a completed cycle with mastery.
6. **Apply once and return.** Finalize a completed review with its report and per-topic schedule history in the same state update. Reconcile interrupted bookkeeping by attempt ID; do not postpone a topic twice or count an answer twice. Leave unanswered topics and aborted attempts unscheduled. Save a precise next action and offer further study without autonomously launching another quiz or future task.
