# Triage Labels

| Role | Local triage value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting evaluation |
| needs-info | needs-info | Awaiting information |
| ready-for-agent | ready-for-agent | Ready for agent implementation |
| ready-for-human | ready-for-human | Requires human action |
| wontfix | wontfix | Will not be actioned |

These values map to the optional `Triage:` field for incoming issues.
Implementation lifecycle uses the separate `Status:` convention in
[issue-tracker.md](issue-tracker.md), including `in-progress` and `done`.
